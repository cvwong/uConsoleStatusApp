# uConsole Status App

## Visual overview

This is a fork from K7BAT uConsole Status App is base on OpieTaylor911's a purpose-built dashboard for the ClockworkPi uConsole.
This version is with out AIO v2 or v1 extension board but with the AC1200 usb-c supported.

## Installation

```bash
cd uConsole-Status-App-v1.1.8
chmod +x install.sh uninstall.sh scripts/*.sh
sudo ./install.sh
```
