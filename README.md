# uConsole Status App

## Visual overview

This is a fork from K7BAT uConsole Status App is base on OpieTaylor911's a purpose-built dashboard for the ClockworkPi uConsole.
This version is for the uConsole without AIO v2 or v1 expension board but with the AC1200 usb-c supported.
